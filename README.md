# 不會寫程式？那就魔法詠唱吧！｜互動簡報還原版

這份專案由使用者上傳的已發布頁面 HTML、`style.css`、`app.js`、`qr.js`、`okayama-itinerary.js`、岡山完成範例 HTML 重建。保留原本 **9 頁**、**20 分鐘** 的簡報文案，不會自行改寫成 40 分鐘版本。

## 觀看

直接在瀏覽器開啟 `index.html`，或將整個資料夾上傳到 GitHub Pages 的發布根目錄。GitHub Pages 預設從 `index.html` 開始。

## 檔案

- `index.html`：九頁互動簡報主頁
- `style.css`：簡報原始樣式（僅更新素材路徑）
- `app.js`：簡報互動、導航、需求詠唱、示範切換、QR
- `qr.js`、`okayama-itinerary.js`：使用者提供的原始腳本
- `assets/academy.png`：對話中已有的魔法書與藍綠傳送門圖片，用來補足原站 CSS 中缺失的 `assets/academy.jpg`
- `demo/index.html`：使用者提供的岡山旅遊五天四夜完成示範頁
- `starter/index.html`：從本對話既有舊版教材 ZIP 擷取的半成品（不是這次使用者上傳檔案的一部分）

## 還原界限

主簡報 DOM、樣式與交互腳本均以使用者的檔案為準；移除了 Chrome 存檔帶入的 ChatGPT Sites 工具列殘留、修復 `.下載` 及瀏覽器另存的 `_files` 相對路徑、移除寫死的螢幕縮放值。

**無法驗證達到 100% 像素等同**：使用者未上傳線上原站的 `assets/academy.jpg`，所以改用本對話先前提供的同主題圖片 `academy.png`；且原站 starter 檔案未直接上傳，因此教材半成品使用先前的舊版 ZIP。部署前應以原站實際畫面再做人工比對。

## 部署

將本資料夾**內的全部內容**放在 GitHub repository 的根目錄，而不是把 ZIP 檔本身上傳為網站，Pages 設定 `main` / `/(root)` 即可。這個 ZIP 不會自動覆寫 GitHub。
